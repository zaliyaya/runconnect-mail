# Почта info@runconnect.ru → Телеграм

Каждые 5 минут GitHub Actions забирает новые письма из Яндекса по IMAP
и пересылает их ботом @runconnect_info_mail_bot в группу «RunConnect почта».
Ящик не меняется: письма читаются только на чтение и остаются непрочитанными.

Секреты репозитория: `IMAP_PASSWORD` (пароль приложения Яндекса), `BOT_TOKEN` (токен бота).
`state.json` хранит номер последнего пересланного письма.

- Тест: Actions → «Почта в Телеграм» → Run workflow → галочка «test».
- Выключить: Actions → «Почта в Телеграм» → ⋯ → Disable workflow.
